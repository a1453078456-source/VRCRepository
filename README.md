# CuteImage

一个只属于自己的可爱图集：把 `image/` 文件夹里的画面，安安静静地摆出来，配一首很轻的背景音乐，再放几句阿尔都塞。

纯静态网页 + 一个 Windows 自带 PowerShell 就能跑的小服务器，**不需要安装任何东西**，不联网也能用。

---

## 打开网站

双击这一层的 **`启动网站.bat`**（推荐）。

- 会弹出一个黑色窗口，地址是 `http://127.0.0.1:8770/`，浏览器会自动打开图集。
- 黑窗口就是服务器本体：**关掉窗口 = 停止网站**。
- 端口被占用也没关系，脚本会自动往后找一个空闲端口，窗口里会写出实际地址。

也可以直接双击 `index.html`——不用服务器也能看图，只是新增图片不会被自动发现（需要重新跑一次素材脚本）。

## 把新图片放进来

1. 把图片（png / jpg / webp / gif / bmp）丢进 `image/` 文件夹；
2. 刷新网页即可出现。

> 走「启动网站.bat」时会实时读取 `image/` 目录，所以新增图片不用改任何代码。
> 如果希望新图片也有更快的缩略图，双击 `重建缩略图.bat` 重新生成一次（需要电脑上有 Python + Pillow）。
> 没有缩略图也能正常显示，只是首次加载会慢一点（直接用原图）。

## 看图的玩法

- 点任意一张卡片 → 大图查看器；
- `←` `→` 前后切换，`空格` 幻灯片自动播放，`F` 收藏，`Esc` 关闭；
- 搜索框支持文件名和日期，比如 `11-10`、`VRChat`、`2026.09`；
- 可以按月份筛选、按「最新 / 最早 / 文件名」排序，收藏会记在浏览器本地；
- 右上角按钮切换明暗主题，选择会被记住；
- 大图里可以「新窗口打开原图」「下载原图」「复制链接」；
- 网址里带图片名（如 `#VRChat_xxx.png`）可以直接分享到某一张。

## 背景音乐

左下角有一个小播放器，默认音量 **20%**，只是背景声。

- 播放 / 暂停、拖动进度条、拖动音量、静音，右下角可以收起成一个小圆钮；
- 浏览器通常会拦一下「自动播放」，这时候点一下页面任意位置（或播放键）就会开始，之后会记住你的选择；
- 音量、是否播放、是否收起都会存在浏览器里，下次打开保持原样；
- 会显示 LRC 里的当前一句歌词。

音乐文件放在 `music/`：

```
music/
├─ DJ阿布 - 咏春 (DJ版).mp3   ← 浏览器能播的音频
├─ DJ阿布 - 咏春 (DJ版).lrc   ← 歌词（可选）
├─ DJ阿布 - 咏春 (DJ版).jpg   ← 封面（可选，同名图片）
└─ DJ阿布 - 咏春 (DJ版).ncm   ← 原文件，留个备份，网页不用它
```

- 文件名写成 `歌手 - 歌名.ext` 就会自动拆出歌手和歌名；
- 加新的音频后，双击 `重建缩略图.bat` 刷新一次清单，播放器就能认出来（播放列表会自动下一首）；
- 封面会缩成 160px 的缩略图放到 `thumbs/`，体积很小；
- 网易云的 `.ncm` 浏览器放不了，已本地转成 mp3（原 `.ncm` 保留在 `music/` 里没动）。

## 阿尔都塞语录

原来「这个网站是怎么来的」那一块换成了语录墙，内容是 `index.html` 里 `#quotes` 这一段，直接改文字即可：

- 一条大引文 + 四条小引文，附出处；
- 引文用宋体排，悬停时左侧会亮起一条渐变细线；
- 目前收的是《意识形态与意识形态国家机器》《列宁与哲学》《答约翰·刘易斯》里的句子。

## 目录结构

```
CuteImage/
├─ 启动网站.bat        ← 双击它打开网站
├─ 重建缩略图.bat      ← 新增图片 / 音乐后可选：重建缩略图与清单
├─ index.html          ← 网站首页（图集 / 语录 / 播放器）
├─ serve.ps1           ← 本地服务器（只监听 127.0.0.1）
├─ image/              ← 你的原图，放在这里（网站按路径引用，不复制、不压缩）
├─ music/              ← 背景音乐、歌词、封面
├─ thumbs/             ← 自动生成的缩略图（图片 + 音乐封面）
├─ assets/
│  ├─ style.css        ← 样式
│  ├─ app.js           ← 交互逻辑（图集 + 灯箱 + 播放器）
│  └─ data.js          ← 清单（由脚本生成，请勿手改）
└─ tools/
   └─ build_gallery.py ← 缩略图 / 歌词 / 封面 / 清单生成脚本
```

## 小提示

- 服务器只绑定 `127.0.0.1`，同一局域网的其他设备访问不到，放心；
- 图片没有被复制或改写，删掉网站文件也不会动到 `image/` 里的原图；
- 想换端口：在命令行执行 `启动网站.bat -Port 9000`；
- 想先不开浏览器：`启动网站.bat -NoBrowser`。
