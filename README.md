# lll 的小站

一个只属于自己的小站：先是一扇欢迎的门，推门进去是 **个人简介**，旁边依次是 **游戏图集**、**我的文章** 和 **我能做什么的**。背景里放着一首很轻的歌，底部留一句自己的话。

纯静态网页 + 一个 Windows 自带 PowerShell 就能跑的小服务器，**不需要安装任何东西**，不联网也能用。

## 打开网站

双击这一层的 **`启动网站.bat`**（推荐）。

- 会弹出一个黑色窗口，地址是 `http://127.0.0.1:8770/`，浏览器会自动打开小站。
- 黑窗口就是服务器本体：**关掉窗口 = 停止网站**。
- 端口被占用也没关系，脚本会自动往后找一个空闲端口，窗口里会写出实际地址。

也可以直接双击 `index.html`——不用服务器也能看，只是新放进来的图片不会被自动发现（需要重新跑一次素材脚本）。

## 部署到 GitHub Pages（公开访问）

小站是纯静态网页，可以直接放到 GitHub Pages 上，不需要服务器：

1. **先想清楚要不要公开**：Pages 上的内容（包括简介里的 QQ、照片、文章，以及 `material-library/` 里的 Word 原件）都是公开的。不想公开的内容先删掉或改掉。
2. 在 GitHub 新建一个 **public** 仓库（比如 `lll-site`）。
3. 把这个 `me/` 文件夹里的内容作为仓库根目录上传：`index.html` 要在仓库根目录。命令行大致是：

   ```bash
   cd "D:\tool\self-madeTool\me"
   git init
   git add .
   git commit -m "lll 的小站"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```

4. 打开仓库的 **Settings → Pages**，把 **Source** 选成 **Deploy from a branch**，分支选 `main`、目录选 `/(root)`，保存。
5. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。如果仓库名是 `<你的用户名>.github.io`，直接访问根域名。

几点说明：

- 已经放好了 `.nojekyll`（让 Pages 跳过 Jekyll，原样发布），以及 `.gitignore`（默认排除没用的 `.ncm` 备份和临时文件）。
- Pages 上没有 PowerShell 服务器，所以「实时发现新图片 / 打开图片文件夹」不可用；代码已自动跳过，一切用 `data.js` 里的清单。**新增图片或文章后，先在本地双击 `重建缩略图.bat`，再 commit + push。**
- 所有路径都是相对路径，放在仓库子目录（比如 `.../仓库名/me/`）也能正常打开。
- GitHub 的单文件限制是 100 MB；现在整个小站（不含 `.ncm`）约 30 MB，可以放心上传。私有仓库想开 Pages 需要付费方案，公开仓库免费。

## 页面是怎么走的

| 地址 | 页面 |
| --- | --- |
| `#/` | 欢迎页：先点「查看 lll 的个人简介」才进站 |
| `#/profile` | 个人简介：头像、性别 / MBTI / QQ、喜欢与不喜欢的东西、近况、简介，以及图集和文章的入口 |
| `#/gallery` | 游戏图集：全部 VRChat 截图，搜索、筛选、排序、收藏、看大图 |

| `#/essays/<文章 slug>` | 读一篇完整的文章 |

导航栏的顺序是：**个人简介 · 游戏图集 · 我的文章 · 我能做什么的**。个人简介页里也单独放了「翻看图集」「读我的文章」两个入口，图集和文章页会横向露出一点内容，方便顺着看。

## 把新内容放进来

所有素材都放在 `material-library/` 里，网页只读取、不移动：

```
material-library/
├─ 个人简介.docx        ← 头像 + 姓名 / MBTI / QQ / 喜好 / 近况 / 简介
├─ image/               ← 图集原图（png / jpg / webp / gif / bmp）
├─ essay/               ← 文章（每篇一个 .docx，标题、日期、正文自动识别）
└─ music/               ← 背景音乐、歌词、封面
```

### 个人简介

直接改 `material-library/个人简介.docx`，保持「标签：内容」的写法即可：

```
头像：          ← 紧跟着插入一张图片
姓名：lll                性别：男
MBTI：intj              QQ：3762832934
喜欢的东西：阅读、游戏、动漫
不喜欢的东西：世界
目前的状态：……
近段时间阅读的书籍……
简介：……
```

改完双击 **`重建缩略图.bat`**（它现在会同时重建图集和内容），刷新网页即可。
只重建简介和文章的话，也可以在命令行跑 `python tools/build_content.py`。

### 文章

把新的 `.docx` 丢进 `material-library/essay/`，会被自动发现：

- 文档里如果有「标题 1」样式的段落，就用它做标题；没有就用文件名；
- 正文每一段就是网页上的一段；
- `1、……` `2、……` 这样的段落会自动变成小标题；
- 「列表段落」样式的文字会排成带 ✦ 的列表；
- 「写于 2026/9/23」这样的句子会作为文末注记，并把日期显示在文章头部；
- 排序按日期从新到旧。

### 图集

1. 把图片丢进 `material-library/image/`；
2. 刷新网页即可出现（走「启动网站.bat」时会实时读取目录）。

> 如果希望新图片也有更快的缩略图，双击 `重建缩略图.bat` 重新生成一次（需要电脑上有 Python + Pillow）。
> 没有缩略图也能正常显示，只是首次加载会慢一点（直接用原图）。

### 音乐

音乐文件放在 `material-library/music/`：

```
music/
├─ DJ阿布 - 咏春 (DJ版).mp3   ← 浏览器能播的音频
├─ DJ阿布 - 咏春 (DJ版).lrc   ← 歌词（可选）
├─ DJ阿布 - 咏春 (DJ版).jpg   ← 封面（可选，同名图片）
└─ DJ阿布 - 咏春 (DJ版).ncm   ← 原文件，留个备份，网页不用它
```

- 文件名写成 `歌手 - 歌名.ext` 就会自动拆出歌手和歌名；
- 加新的音频后，双击 `重建缩略图.bat` 刷新一次清单，播放器就能认出来（正在播放时，一首结束会自动接下一首）；
- 封面会缩成 160px 的缩略图放到 `thumbs/`，体积很小。

## 看图的玩法

- 点任意一张卡片 → 大图查看器；
- `←` `→` 前后切换，`空格` 幻灯片自动播放，`F` 收藏，`Esc` 关闭；
- 搜索框支持文件名和日期，比如 `11-10`、`VRChat`、`2026.09`；
- 可以按月份筛选、按「最新 / 最早 / 文件名」排序，收藏会记在浏览器本地；
- 右上角按钮切换明暗主题，选择会被记住；
- 大图里可以「新窗口打开原图」「下载原图」「复制当前图片的链接」；
- 网址里带图片名（如 `#/gallery/VRChat_xxx.png`）可以直接分享到某一张。

## 背景音乐

默认音量 **20%**，只是背景声。**不会自动播放**：进入小站后，左下角只有一个收起的小圆钮，点开它、再点播放键才会响。

- 播放 / 暂停、拖动进度条、拖动音量、静音，左下角可以收起成一个小圆钮；
- 浏览器有时会拦一下播放，如果没响就再点一次播放键；
- 音量会存在浏览器里，下次打开保持原样（但不会自动开始播放）；
- 会显示 LRC 里的当前一句歌词。

## 我的名言

欢迎页底部、个人简介页底部都会展示这一句话：

> 我们总是要不断地前行，然后抵达我们观念中的目的地，尽管我们为此会迂回许多次。

这一句用宋体排，悬停时左侧会亮起一条渐变细线，落款是 `lll`。

想换文字，改 `assets/app.js` 顶部的 `QUOTES` 数组即可（欢迎页和个人简介页都会跟着变）。

## 目录结构

```
me/
├─ 启动网站.bat        ← 双击它打开小站
├─ 重建缩略图.bat      ← 改了图片 / 音乐 / 简介 / 文章后双击它
├─ index.html          ← 网站骨架（欢迎页 + 各个视图 + 灯箱 + 播放器）
├─ serve.ps1           ← 本地服务器（只监听 127.0.0.1）
├─ material-library/   ← 所有原始素材（Word / 图片 / 文章 / 音乐）
├─ preview/            ← 效果截图
├─ thumbs/             ← 自动生成的缩略图（图片 + 音乐封面）
├─ assets/
│  ├─ style.css        ← 样式
│  ├─ app.js           ← 路由、简介 / 文章渲染、图集、灯箱、播放器
│  ├─ content.js       ← 简介 + 文章清单（由脚本生成，请勿手改）
│  ├─ avatar.jpg       ← 从简介 docx 里自动取出的头像
│  └─ data.js          ← 图集 + 音乐清单（由脚本生成，请勿手改）
└─ tools/
   ├─ build_gallery.py ← 缩略图 / 歌词 / 封面 / 图集清单生成脚本
   └─ build_content.py ← 简介 / 文章 → content.js 生成脚本
```

## 小提示

- 服务器只绑定 `127.0.0.1`，同一局域网的其他设备访问不到，放心；
- 图片没有被复制或改写，删掉网站文件也不会动到 `material-library/` 里的原图；
- 想换端口：在命令行执行 `启动网站.bat -Port 9000`；
- 想先不开浏览器：`启动网站.bat -NoBrowser`；
- 页面切换用地址栏里的 `#/...`，刷新以后还停在原来那一页。
